# Python Programmer Skills Programme – Level 4

Welcome to the Python Programmer Skills Programme, where you will build essential tech skills to prepare for your future in technology. This is Level Two of the course, and this guide is here to help you navigate its structure, submit your tasks, and succeed in your journey as a Python programmer.

## Programme Structure

The programme consists of two core components:

### 1. Knowledge (Theory) Component

This component provides all the foundational theory you need to understand Python programming concepts. It is divided into Knowledge Modules (KMs), each of which contains several Knowledge Topics (KTs) covering specific concepts.

#### Knowledge Modules

The following modules are available in your GitHub repository, each organized as a folder named according to the format `L4T[number]`, which stands for `Level 4 Task [number]`. For instance, `L4T01` refers to `Level 4 Task 1`.

- L4T01 – Introduction to Python Programming
- L4T03 – Python Data Types and Structures
- L4T05 – Principles of Programming with Python
- L4T07 – Intermediate Programming Principles in Python
- L4T09 – REST API and GUI in Python

EEach Knowledge Module folder on GitHub contains a PDF Learner Guide that covers the course content for the topics listed on your dashboard. After reviewing each Knowledge Topic, you’ll complete both a formative and a summative assessment to check your understanding. These assessments are organised in your workbook by Knowledge Topic, each labeled with a unique code to help you and your facilitator find them quickly.

#### Knowledge Topic Naming Convention

Each topic follows this format:

`KM-[ModuleNumber]-KT[TopicNumber] – Topic Title`

**Example:**  
`KM-01-KT01 – Computers`  
This refers to Knowledge Module 1, Knowledge Topic 1, covering the topic "Computers".

Read the topic content carefully before attempting the assessments to ensure you understand the material.

#### Completing and Submitting Assessments

Each Knowledge module document explains how to access the workbook - a document where you will answer the assessment questions. This guidance can usually be found within the first few pages of the module.

Once completed:

- Save your workbook in the correct GitHub folder.  
  For example, if you’re working on answering questions for Knowledge Module 1's Knowledge Topics, upload your workbook to the `L4T01 – Introduction to Python Programming` github folder.

- Visit the dashboard and request a facilitator review for the Knowledge Topic(s) you’ve completed.

You may request review ONLY after completing BOTH the fommative & summative assessment of each topic

### 2. Application (Practical) Component

This component allows you to apply what you've learned through hands-on practical tasks. Unlike the Knowledge Topic assessments, these tasks place a deeper focus on skill application.

These tasks are systematically organized into Practical Skills Modules, abbreviated as PM. Each module covers a specific set of learning objectives and is labeled with the format:
`Python Programmer PM[number]`

- PM stands for Practical Module.
- The number following PM indicates the module sequence within the curriculum.
  **For example**:
- Python Programmer PM1 refers to Practical Module 1

`Python Programmer PM[number]`

#### Practical Modules in your GitHub folder:

- L4T02 – Python Programmer PM1
- L4T04 – Python Programmer PM2
- L4T06 – Python Programmer PM3
- L4T08 – Python Programmer PM4
- L4T10 – Python Programmer PM5
- L4T11 – Python Programmer PM6

Each Practical Module folder includes:

- Subfolders for individual practical tasks
- A guide document explaining the expectations for the module

#### Completing Practical Tasks

- Open the relevant task folder
- Complete the task as instructed in the module guide
- Upload your completed work inside the correct folder

#### Submitting Practical Tasks

When submitting via the dashboard, tasks are listed in the following format:

`PM[number] – Name of the Practical Task`

**Example:**  
`PM1 – Basic Computer Skills`  
This refers to a task in Practical Module 1 focused on Basic Computer Skills.

## Final Note

Stay focused, follow the instructions in each module carefully, and complete your work to the best of your ability. Don’t hesitate to reach out to your facilitators for guidance and support throughout the programme.

We wish you all the best on your learning journey.
